# Published native homogeneous run

The executed source files and protocol are byte-identical to the local completed run. README.md is the original execution note. This is the training-loss aggregation version, not the earlier server validation-loss variant.

From repository root (Python 3.13.5, Windows execution environment):

```powershell
python -m pip install -r experiments/homogeneous/fedcpdp-native-20261114/requirements.txt
python scripts/prepare_native_fedcpdp_data.py --download
$env:PYTHONHASHSEED='0'
python experiments/homogeneous/fedcpdp-native-20261114/preflight.py
python experiments/homogeneous/fedcpdp-native-20261114/schedule.py --workers 2
python experiments/homogeneous/fedcpdp-native-20261114/summarize.py
```

On Linux use `export PYTHONHASHSEED=0`; bitwise cross-platform equality is not promised. Data preparation also accepts `--archive /path/to/Dataset.zip`. It checks all CSV hashes before writing. Third-party data are retrieved from the pinned author commit, not redistributed or relicensed here.

Source validation is used for thresholds only. All 300 models use 50 rounds, five local epochs, batch 32, ten seeds, no ensemble. The final model is pre-specified; test labels never choose model or threshold. See protocol.json for DP and target access limitations.

The completed scores and per-record predictions are in [results](../../../results/fedcpdp-native-homogeneous-20261114/README.md). To inspect published predictions without training, use `python scripts/verify_native_fedcpdp_publication.py`. Only load pickle checkpoints generated by your own trusted run. Published results remain separate from newly generated experiment runs.
