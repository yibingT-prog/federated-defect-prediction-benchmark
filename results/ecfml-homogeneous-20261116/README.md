# ECFML 同构实验结果

2026-11-16 完成并通过核验：**30 个目标 × 10 个种子 = 300 个正式任务，每次 50 轮，失败 0**。覆盖五个家族全部30个目标。

这是保留完整方法机制、明确注明差异的重实现，不是未经修改的作者代码或论文表格数值的严格复现。

## 数据权限与解释

目标项目约80%有标签支持集适配，约20% query测试；不是目标完全无标签条件。 各家族分别留一项目，源训练/验证继续使用冻结v3行号；不新增跨客户端重复分组。固定划分下的10个种子只衡量训练随机性，不代表跨划分置信区间。

两种资源条件及目标测试记录不同；本页不与FLR、ALMITY、FedCPDP或另一资源条件作无条件总排名。FedDP的公共项目保留还改变了私人源项目名单，不能仅按相同目标名称视为同条件。

## 主结果

先对每个项目的10个种子取均值，再对项目等权汇总：ROC_AUC 0.7409，MCC 0.2548，Recall 0.4903，G_mean 0.5625，F1 0.3790，CostEffect@20 0.2882，Popt@20 0.3267。

主口径为最后轮模型、源验证客户端宏MCC选阈值；并保留固定0.5阈值结果。工作量指标沿用统一LOC预算定义，不是运行时间；原项目有无效LOC则记为N/A，宏均值只使用有效项目。

ECFML最终模型包含目标支持集适配。论文未公布的网络宽度、C=0.0001裁剪界限等为已记录研究设置；50 epochs明确解释为50次联邦元更新。保留Laplace机制不表示已证明端到端形式化隐私预算。

## 文件和核验

- `all_runs.csv`：每次正式任务的指标；`project_summary.csv`、`family_summary.csv`：项目和家族统计。
- `runs/<target>/<seed>/`：指标、目标与源验证预测、数据行号/预处理审计、完整逐轮训练记录。另含模型配置。
- `verification.json`：预测重算核验记录；`model_verification.json`：全部保存模型重新加载后与预测一致的核验记录。
- `publication_manifest.json`：发布文件哈希；`local_artifact_sha256.json`：包含未发布检查点/日志在内的原始产物哈希。

原始数据、模型二进制、日志和试跑不进入Git；数据通过固定上游提交和30个CSV哈希重建。核验已发布结果不需要下载数据或安装PyTorch：

```bash
python scripts/verify_resource_publication.py --method ecfml
```
